
# Agent Instructions

- Use the simplest code that works.
- Add nothing I did not ask for.
- Use plain HTML, CSS, and JavaScript.
- Use Chrome Manifest V3.
- Do not use React or Tailwind.
- Do not include API keys.
- Keep permissions limited to what is needed.
- Make the interface simple and accessible.
- Handle invalid input and unsupported pages.
- Write readable code with clear variable names.
- Do not claim tests passed unless they were run.
- Commit changes in small, meaningful steps.
