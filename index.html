YouTube Study Focus

Hide YouTube recommendations and comments while you study. Turn Focus Mode on or off and optionally start a 1–180 minute timer.

Install in Chrome

  1. Click Code on the GitHub repository page.
  2. Click Download ZIP.
  3. Unzip the downloaded file.
  4. Open chrome://extensions.
  5. Turn on Developer mode.
  6. Click Load unpacked.
  7. Pick the unzipped folder that contains manifest.json.

After installation, open a page on YouTube and click the extension icon.
